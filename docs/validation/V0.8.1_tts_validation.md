# V0.8.1 TTS Identification Validation

## Kapsam

V0.8.1 doğrulaması experimental data quality'den V0.8.0 runtime provider
round-trip'ine kadar sekiz ayrı CTest programı kullanır. Bunlar deneysel
korelasyon değil, synthetic known-truth **analytical code verification**
testleridir.

## Test Aileleri

- `tms26.tts_data_model`: family common state, explicit quality, ordering,
  positive Kelvin ve authoritative modulus koşulları.
- `tms26.tts_scalar_minimizer`: quadratic Brent truth, valid bracket ve
  no-interior rejection.
- `tms26.tts_pair_shift`: feasible domain, exact integral, irregular grids,
  quality gaps, zero loss, joint/storage-only/G''-only/no-support ve plateau.
- `tms26.tts_shift_chain`: reference zero shift, colder/hotter cumulative
  shifts, temperature ordering, missing reference ve broken chain.
- `tms26.tts_master_curve`: provenance cloud, low/high/both/no extension,
  duplicate priority, strict ordering, boundary diagnostics ve quality filter.
- `tms26.tts_diagnostics`: analytical VGP magnitude/phase ve Cole-Cole data.
- `tms26.tts_identification`: exact TRS, deterministic non-TRS, weak
  identifiability, deep-copy ve invalid/broken top-level status.
- `tms26.tts_runtime_roundtrip`: V0.8.1 output → mevcut V0.8.0 provider'ları →
  physical `(f,T)` sorgusu.

## Synthetic Exact TRS

Temperature seti `253.15, 273.15, 293.15, 313.15, 333.15 K`; explicit
reference `293.15 K`; known shifts `s=[2,1,0,-1,-2]` olarak kullanılır.
Synthetic log-modulus response nonzero linear slopes taşır. Bu seçim exact
piecewise-linear objective'in sample density veya irregular frequency spacing
etkisinden bağımsız olarak bilinen horizontal shift'i geri kazanmasını sağlar.

Absolute/relative Brent stopping scale yaklaşık `1.2e-7` olduğundan recovered
pair ve chain shift acceptance `1.5e-6` boyutsuz seviyesindedir. Exact residual
integral ve identity kontrolleri `1e-12`–`1e-14` ölçeğindedir. Bu toleranslar
measurement uncertainty değildir.

## Deterministic Non-TRS

Storage ve loss branch'leri farklı temperature shifts ile üretilir. Beklenen
kanıtlar:

- exact TRS'den daha yüksek joint residual,
- belirgin `|delta_s_storage-delta_s_loss|`,
- temperature/source provenance taşıyan ayrışmış VGP ve Cole-Cole clouds.

Program bu veriyi smoothing veya global optimization ile kusursuz collapse'a
zorlamaz ve universal TRS PASS/FAIL üretmez.

## Weak Identifiability

Nearly-flat log-modulus slopes ile optimizer numerical minimum bulsa bile
objective curvature güçlü response'a göre çok düşük kalır. Tam plateau'da
machine-scale objective gürültüsü gerçek interior bracket sayılmaz; Brent
çağrılmaz ve `PAIR_SHIFT_NO_INTERIOR_MINIMUM` döner.

## Quality Gaps ve Zero Loss

`VALID, VALID, FLOOR, VALID, VALID` loss dizisi iki ayrı segment üretir.
Objective floor noktasının üzerinden interpolation yapmaz. `VALID,G''=0`
validation/runtime export'ta korunur fakat loss log-objective dışında kalır;
epsilon substitution testi yoktur çünkü üretim kodunda da uygulanmaz.

## Stitching Matrix

Runtime table testleri aşağıdakileri ayrı doğrular:

- low-side extension,
- high-side extension,
- aynı source'tan both-side extension,
- no-extension'ın normal durum olması,
- machine-equivalent duplicate frequency,
- reference ve nearest-temperature priority,
- strict frequency ordering,
- boundary gap ve exact-TRS mismatch,
- unreliable loss-quality point'in export dışında kalması.

Bütün overlap measurements experimental cloud'da kalır.

## Runtime Round Trip

Üç synthetic isotherm identify edilir; stitched modulus table ve empirical
shift table mevcut `tabulated_dynamic_modulus_provider_t`,
`tabulated_log10_shift_provider_t` ve
`thermorheological_dynamic_modulus_provider_t` nesnelerine dönüştürülür.
Farklı physical `(f,T)` sorguları aynı independent known master point'e düşer:

```text
f_r = a_T f
G'(f,T) = G'_truth(f_r)
G''(f,T) = G''_truth(f_r)
```

Yeni harmonic API çağrılmaz.

## Numerical Memory/Bounds Audit

Yeni test aileleri ayrıca GNU Fortran `-fcheck=all -fbacktrace` geçici Debug
build'inde çalıştırılmıştır. Shift-chain yolu 100 ardışık koşuda doğrulanmış;
coarse-scan bracket seçimindeki Fortran short-circuit varsayımı kaldırılarak
index-0 erişim regresyonu kapatılmıştır.
