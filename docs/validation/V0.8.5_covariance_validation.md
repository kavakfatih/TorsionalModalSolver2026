# V0.8.5 Covariance Validation

## Validation strategy

V0.8.5 tests production yordamlarını doğrudan çağırır. Analytical integraller
üretim antiderivative'ından bağımsız adaptive numerical oracle ile
karşılaştırılır. Toleranslar algorithmic floating-point regression içindir;
rubber acceptance veya TRS pass/fail limiti değildir.

## `tms26.tts_covariance_propagation`

- `G'=M cos(delta)`, `G''=M sin(delta)` ve `J Sigma J^T` hand calculation,
- independent M/delta input'larından nonzero `Cov(G',G'')`,
- physical Pa² → dimensionless log covariance,
- linear/log correlation invariance,
- Pa↔MPa consistent scale invariance,
- `G'<=0` ve `G''<=0` rejection,
- explicit first-order provenance.

## `tms26.tts_covariance_validation`

- symmetric SPD, determinant ve correlation diagnostics,
- zero/negative/nonfinite diagonal ve covariance rejection,
- determinant negative/zero ve `rho=+/-1` rejection,
- reciprocal-condition based near-singular status; no regularization,
- V0.8.4 `u_G²` diagonal consistency,
- duplicate `(T,f)` rejection, shuffled array order independence,
- 1–2–5–10–20 Hz fixture'ında 5 Hz gap → `[1,2]` ve `[10,20]`,
- convex full-matrix interpolation'ın seçili alpha noktalarında SPD kalması.

## `tms26.tts_mahalanobis_integrals`

On vaka kapsanır:

1. constant covariance,
2. diagonal constant covariance ve existing scalar weighted limit,
3. nonconstant linear covariance,
4. positive covariance,
5. negative covariance,
6. nearly-linear determinant,
7. quadratic denominator,
8. near-constant matrix slope,
9. SPD interpolation,
10. near-singular interval rejection.

Expected integraller independent adaptive Simpson oracle ile hesaplanır.
Production'da fixed dense grid yoktur.

## `tms26.tts_mahalanobis_pair_shift`

- positive `rho`: `d²([1,1]) < d²([1,-1])`, negative `rho` ters yön,
- zero-covariance matched-diagonal limit,
- controlled positive/negative correlation shift yönü,
- `Sigma -> lambda² Sigma` objective/minimizer invariance,
- covariance gap ve bivariate overlap,
- no overlap ve flat/no-interior status,
- loss unavailable iken no storage-only fallback.

## `tms26.tts_covariance_sensitivity`

- V0.8.1 baseline, V0.8.4 original weighted, matched diagonal ve Mahalanobis
  shift'lerinin ayrı tutulması,
- `delta_support`, `delta_covariance`, `delta_total` identities,
- zero-off-diagonal + dar covariance support fixture'ında support-only effect,
- identical support + controlled correlation fixture'ında pure covariance
  effect ve predicted direction,
- identification, source family, master/runtime arrays, V0.8.4 uncertainty ve
  V0.8.5 covariance input'larının bit-level immutability kontrolü,
- first-order/cross-channel/cross-isotherm/cross-frequency/regularization flags.

## Interpretation boundary

Small `delta_covariance` TRS kanıtı değildir. Large delta otomatik bad-data
kararı değildir. SPD covariance physical uncertainty model validation'ı
değildir. Test sonucu yalnız implementation equations ve declared scope'un
deterministic regression kanıtıdır.
