# V0.8.2 Parametric Shift-Law Identification Architecture

## Amaç ve sınır

V0.8.2, V0.8.1 tarafından üretilmiş empirical temperature-shift evidence'ı
üzerine iki additive approximation kurar: Arrhenius ve Williams-Landel-Ferry
(WLF). Empirical shift table, master cloud ve stitched runtime master table
authoritative kalır. Parametric fit bunları yeniden hizalamaz, overwrite etmez
ve iki model arasında automatic winner seçmez.

```text
measured DMA isotherms
  -> V0.8.1 adjacent pair results: delta_s = s_j - s_i
  -> V0.8.2 Arrhenius fit / profiled WLF fit
  -> residual + identifiability + LOTO evidence
  -> explicit runtime model choice
```

Canonical TMS26 convention değişmez:

```text
s(T) = log10(a_T)
f_r = a_T f
log10(f_r) = log10(f) + s(T)
```

## Modül sorumlulukları

- `tms_tts_shift_law_types`, pair observation ile Arrhenius/WLF result ve
  LOTO diagnostic tiplerini taşır. `best_model` alanı içermez.
- `tms_tts_shift_law_fit`, pair-space analytical Arrhenius ve profiled-1D WLF
  matematiğini uygular. Generic `tms_scalar_minimizer` yalnız C2 refinement
  için kullanılır.
- `tms_tts_shift_law_validation`, V0.8.1 pair provenance'ını temperature
  endpoint'leriyle birleştirir ve LOTO fold'larını yönetir.
- `tms_tts_parametric_runtime_export`, mevcut V0.8.1 master provider ile
  mevcut V0.8.0 Arrhenius/WLF shift provider'larını bileştirir.

## Dependency yönü

```text
core + numerics
       |
runtime materials/providers
       |
V0.8.1 identification result
       |
V0.8.2 fit + validation
       |
explicit parametric runtime export
```

Runtime material modülleri identification modüllerini import etmez.
Identification/export katmanı mevcut runtime-compatible nesneleri oluşturur;
harmonic veya modal solver'da yeni API yoktur.

## Pair-space input

Primary gözlem `delta_s_ij=s(T_j)-s(T_i)` değeridir. Cumulative absolute shift
chain fit observation olarak kullanılmaz; böylece accumulation error bağımsız
ölçümlermiş gibi sayılmaz. Adjacent pair'ler shared isotherm nedeniyle
correlated olabilir. Covariance bilinmediğinden V0.8.2 equal weights kullanır;
overlap, curvature veya pair objective inverse-variance weight değildir.

## Availability ayrımı

- `fit_available`: matematiksel parameter approximation üretildi.
- `residual_validation_available`: observation count model parameter sayısını
  aşıyor.
- `predictive_validation_available`: LOTO fold'larının tamamı çözülebildi.
- `parameter_identifiable`: yalnız WLF C1 ve C2'nin finite interior minimum ile
  ayrı ayrı belirlenebildiğini gösterir.

Başarı, gerçek elastomerin ilgili yasaya kesin olarak uyduğu anlamına gelmez.

## Runtime export

Arrhenius export pozitif finite `Ea_app`; WLF export ise ayrıca identifiable,
positive ve pole-safe C1/C2 ister. Master G'/G'' tablosu empirical runtime
export'tan aynen alınır. Sıcaklık domain'i measured `Tmin..Tmax` aralığıdır;
extrapolation yoktur. Predictive validation unavailable olması metadata'da
korunur fakat automatic selection üretilmez. Poorly identified WLF runtime'a
açılmaz.

## Geriye uyumluluk

`identify_tts_master_curve()` ve `create_tts_runtime_export()` değişmeden
kalır. V0.5 modal, V0.6 harmonic, V0.7 dynamic material, V0.8.0
thermorheological runtime ve V0.8.1 empirical identification yolları additive
V0.8.2 katmanından bağımsız çalışmayı sürdürür.
