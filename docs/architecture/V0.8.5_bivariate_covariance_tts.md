# V0.8.5 Point-Local Bivariate Covariance TTS Mimarisi

## Amaç

V0.8.5, V0.8.4'ün diagonal pointwise standard uncertainty modelini aynı
fiziksel DMA noktasındaki `Cov(G',G'')` ile genişletir. Sonuç yalnız offline
sensitivity evidence'dır; **full GLS değildir**. Modellenen bağımlılık:

```text
aynı (temperature, frequency) noktası
                 G' <----> G''
```

Cross-frequency, cross-temperature, cross-isotherm, common-mode calibration,
frequency-axis ve temperature-axis covariance bu sürümde yoktur.

## Authoritative sonuç hiyerarşisi

Her adjacent pair dört ayrı sonuç taşır:

1. `s_baseline`: V0.8.1 authoritative empirical shift,
2. `s_weighted_original`: değişmeden çağrılan V0.8.4 weighted-L2 sonucu,
3. `s_diagonal_matched_support`: V0.8.5 `O_B` desteğinde diagonal kontrol,
4. `s_mahalanobis`: aynı `O_B` üzerinde point-local covariance sonucu.

`pair_shift_results`, `empirical_shifts`, `master_cloud`,
`runtime_master_table` ve `source_family` yeniden kurulmaz. Sonuç modelinde
preferred shift yoktur.

## Modüller ve bağımlılık yönü

- `tms_bivariate_covariance_integrals`: lineer residual/2x2 covariance için
  grid-free rational integral.
- `tms_tts_covariance_types`: Pa² overlay, status, segment, pair ve top-level
  result sözleşmeleri.
- `tms_tts_covariance_propagation`: polar ve log-space Jacobian propagation,
  SPD/conditioning ve point Cholesky diagnostic.
- `tms_tts_covariance_validation`: physical-key eşleme, diagonal consistency,
  gap-aware bivariate segment ve covariance-matrix interpolation.
- `tms_tts_mahalanobis_pair_shift`: aynı support'taki diagonal/Mahalanobis
  objective ve mevcut Brent mimarisi.
- `tms_tts_covariance_sensitivity`: V0.8.1/V0.8.4 sonuçlarını okuyup dört shift
  ile üç sensitivity delta'sını bir araya getirir.

```text
core + numerics
       |
V0.8.1 empirical TTS
       |
V0.8.4 diagonal uncertainty sensitivity
       |
V0.8.5 point-local covariance sensitivity
```

Runtime material, modal ve harmonic katmanlar V0.8.5 modüllerini import etmez.

## API ve tek diyagonal kaynağı sözleşmesi

Top-level API measurement identification, V0.8.4 uncertainty family ve
V0.8.5 covariance family kabul eder. V0.8.5 için canonical matrix kaynağı
physical G-space covariance family'dir. İki input kabul edildiğinden
`Var(G')=u_G'^2` ve `Var(G'')=u_G''^2` machine-equivalence ile zorunlu
doğrulanır. Uyuşmazlıkta iki kaynaktan biri sessizce seçilmez; açık
`DATA_MISMATCH` döner. `s_weighted_original` mevcut V0.8.4 yordamıyla hesaplanır.

## Support ve interpolation

`O_B`; positive/valid storage, positive/valid loss, iki uncertainty channel'ı
ve valid SPD covariance desteğinin kesişimidir. Missing covariance gerçek
gap'tir. Gap bridge edilmez, extrapolation yapılmaz ve storage-only
Mahalanobis fallback yoktur.

Valid contiguous segment içinde full covariance matrix elemanları
`x=log10(f)` üzerinde lineer interpolate edilir. Correlation veya standard
deviation ayrı interpolate edilmez. Bu, TMS26 deterministic covariance
interpolation politikasıdır; universal fizik yasası değildir.

## Mühendislik zinciri

```text
raw-material tests (rheometer, tensile, M100/M300, hardness, density)
  -> compound / injection / curing / process parameters
  -> dynamic material measurements
  -> V0.8.1 empirical TTS
  -> V0.8.2 WLF / Arrhenius evidence
  -> V0.8.3 repeatability / bootstrap uncertainty
  -> V0.8.4 diagonal measurement-uncertainty sensitivity
  -> V0.8.5 G'/G'' covariance-aware sensitivity
  -> G'(f,T), G''(f,T)
  -> K'(f,T), K''(f,T)
  -> TVD harmonic response
  -> crank-pulley angle / torque / stiffness / fatigue / strength tests
  -> test / CAE correlation
  -> material and process tolerances
  -> raw-material specifications and production validation
```

DMA covariance modeli TVD ürün-seviyesi covariance değildir. SPD bir input
matrix de fiziksel uncertainty modelinin yeterliliğini tek başına kanıtlamaz.

## V0.8.6 sınırı

Common calibration gain, geometry factor, systematic phase offset, fixture
compliance, common temperature offset ve cross-frequency/isotherm covariance
low-rank nuisance-source veya correlated-field modeli gerektirir. Bunlar
V0.8.6'ya ayrılmıştır; V0.8.5 dense full-spectrum matrix üretmez.
