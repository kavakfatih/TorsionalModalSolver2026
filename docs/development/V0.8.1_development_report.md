# TMS26 V0.8.1 Development Report

Bu belge measured dynamic-elastomer isotherm'lerden empirical shift table ve
solver-ready master table üreten V0.8.1 foundation'ın kalıcı geliştirme
kaydını tutar.

## L2 — System Architecture

### Identification Boundary

Experimental types, quality semantics, pair optimization ve TRS evidence
`engine/src/identification/` altında tutulur. Generic scalar minimizer
`engine/src/numerics/` altındadır. Existing materials/runtime ve harmonic
katmanları identification ayrıntılarına bağımlı değildir.

### Data Flow

```text
measured isotherms + common state + explicit reference
  -> validation
  -> contiguous channel segments
  -> adjacent pair shifts
  -> empirical absolute shift chain
  -> experimental master cloud
  -> TRS evidence
  -> reference-centered runtime table
  -> existing V0.8.0 providers
```

### Runtime Integration

`tms_tts_runtime_export` yalnız mevcut
`tabulated_dynamic_modulus_provider_t`,
`tabulated_log10_shift_provider_t` ve
`thermorheological_dynamic_modulus_provider_t` constructor'larını kullanır.
`analyze_material_aware_harmonic_response()` veya solver backend'i
değiştirilmemiştir.

### Result Model

Top-level result overall status, explicit reference, pair results, absolute
shifts, full master cloud, runtime table, VGP/Cole-Cole/boundary evidence ve
availability flags taşır. Input family deep-copy edilir. `SUCCESS`, numerical
construction anlamındadır; universal TRS validity değildir.

## L3 — Technical

### Experimental Data Model

Family common material/batch, strain amplitude, prestrain, deformation mode,
conditioning ve test source state'ini bir kez tutar. Isotherm specimen/source
ve ordered points taşır. Different batch silent merge edilmez.

### Quality Segments

Explicit `VALID`, `BELOW_RELIABLE_FLOOR`, `UNAVAILABLE`, `REJECTED` değerleri
vardır. Storage segmenti `G'>0`, loss-log segmenti `G''>0`, runtime point ise
`G''>=0` ister. Invalid gap üzerinden interpolation yoktur; zero valid loss için
epsilon substitution yapılmaz.

### Log-Frequency Coordinate

Canonical convention `x=log10(f)`, `s=log10(a_T)`, `x_r=x+s` ve
`f_r=a_Tf` olarak korunur. Pair relative shift moving curve'e eklenir.

### Pair Objective

Measured domains feasible shift intervalini belirler. Storage ve loss
log-modulus residual'ları kendi valid overlap measure'larıyla normalize edilir;
joint objective iki normalized channel'ın eşit ağırlıklı ortalamasıdır.

### Exact Residual Integral

Bir subinterval'da linear residual için
`h/3(r0^2+r0*r1+r1^2)` exact integral kullanılır. Fixed grid sampling
authoritative değildir; irregular spacing ve sample-density testiyle korunur.

### Coarse Scan

Default 65 deterministic point feasible domain'in açık interior'unda taranır.
Objective validity ve value ayrı tutulur. 65 bir physical constant değil,
named configuration default'udur.

### Brent Bracketing

Generic minimizer yalnız `J[k-1]>J[k]<J[k+1]` gerçek interior bracket alır.
Machine-scale plateau gürültüsü `64 epsilon max(1,|J|)` numerical drop
kontrolüyle bracket sayılmaz. Default stopping scale `8 sqrt(epsilon(dp))`'dir.

### Shift Chain

Explicit reference `s=0,a_T=1` ile anchor edilir. Temperature-sorted index
listesinde colder/hotter yönlere adjacent ilerlenir. Link failure
`CHAIN_BROKEN` üretir; non-adjacent bridge yoktur.

### Master Cloud

Bütün original measured values, quality ve specimen/source provenance korunur.
Applied `s` ve calculated `f_r` yeni alanlardır; original frequency overwrite
edilmez. Cloud validation truth olarak kalır.

### Runtime Stitching

Reference points önce alınır; diğer curves temperature distance sırasıyla
yalnız range extension sağlar. Low/high/both-side extension desteklenir,
no-extension error değildir. Duplicate priority deterministic; averaging,
smoothing ve spline yoktur.

### VGP

Her VALID complex point için `|G*|=hypot(G',G'')` [Pa] ve
`delta=atan2(G'',G')` [rad] temperature/source provenance ile üretilir.

### Cole-Cole

Her VALID complex point için linear-axis `G''` vs `G'` [Pa] cloud üretilir.
Tek scalar TRS score veya threshold yoktur.

## Validation

### Exact TRS

Beş temperature ve known `s=[2,1,0,-1,-2]` synthetic truth ile pair/absolute
shifts, empirical table, master cloud, stitching ve full-complex evidence
doğrulanır.

### Non-TRS

Storage ve loss için farklı shift family'leri daha yüksek joint residual ve
storage-loss shift discrepancy üretir. Algorithm bunu kusursuz collapse'a
zorlamaz.

### Weak Identifiability

Nearly-flat response numerical minimum üretse bile curvature güçlü response'a
göre düşüktür. Tam plateau/no-interior durumda Brent çağrılmaz.

### Quality Gaps

Floor point iki loss segmenti ayırır. Valid zero loss runtime'a girebilir fakat
loss-log objective dışında kalır.

### Storage-Only

G' support yeterli ve positive-valid G'' support yetersiz olduğunda shift açık
`SHIFT_FROM_STORAGE_ONLY` diagnostic'iyle sağlanır.

### Runtime Round Trip

Multiple synthetic isotherm → identification → stitched/shift tables → mevcut
V0.8.0 providers → physical `(f,T)` sorgusu zinciri independent known truth ile
karşılaştırılır.

### Numerical Bounds Audit

GNU Fortran `-fcheck=all -fbacktrace` build'inde bütün yeni test aileleri
geçmiştir. Shift-chain 100 ardışık kez çalıştırılmış; Fortran short-circuit
varsayımından kaynaklanan coarse-scan index-0 erişimi regression öncesinde
tespit edilip güvenli iki aşamalı dallanmayla düzeltilmiştir.

## Hardening Review Closure

### Runtime Quality-Gap Problemi

Initial stitching yalnız unusable point'i runtime table dışında bırakıyordu.
V0.8.0 tabulated provider tabloyu continuous gördüğünden, iki valid point
arasındaki internal `FLOOR/UNAVAILABLE/REJECTED` ölçüm hole'u üzerinde sessiz
interpolation oluşabiliyordu. Pair objective quality segmentleri doğru olsa da
measurement-quality bilgisi solver sınırına kadar korunmuyordu.

### Reduced-Frequency Interval-Union Çözümü

Her source isotherm'de iki adjacent point ancak ikisi de `VALID G'>0` ve
`VALID G''>=0` ise runtime coverage interval'ı oluşturur. Bu interval'lar
`x_r=log10(f)+s` eksenine taşınır, lower endpoint'e göre sıralanır ve yalnız
overlap veya machine-equivalent touching durumunda birleştirilir. Final runtime
table'ın `[min(log10(f_r)),max(log10(f_r))]` domain'i tek bir merged coverage
tarafından tamamen desteklenmiyorsa
`TTS_IDENTIFICATION_RUNTIME_DOMAIN_GAP` döner ve
`runtime_export_ready=.false.` kalır.

### Edge Gap ve Cross-Isotherm Bridge

Edge'deki invalid points runtime domain'ini ilk/son supported contiguous
interval'a daraltabilir. Internal hole başka bir shifted isotherm'in gerçek
adjacent valid interval'larıyla tamamen örtülüyorsa global union continuous
kabul edilir. Source-local invalid point bütün dataset'i otomatik reddetmez.

### Valid Zero Loss

`G''=0, quality=VALID` runtime interval endpoint'i olarak geçerlidir; passive
zero-loss state provider table'da korunur. Aynı nokta `log10(0)` tanımsız
olduğundan loss pair objective segmentine alınmaz. Epsilon clamp eklenmemiştir.

### Reduced-Frequency Overflow/Underflow

`f_r` önce `log10(f_r)=log10(f)+s` koordinatında doğrulanır. Nonfinite input,
overflow ve underflow exponentiation öncesi clean failure üretir; `huge()` veya
zero sentinel runtime frequency olarak kabul edilmez. Shift chain'in derived
`a_T=10^s` alanı aynı representability policy'sini kullanır; primary quantity
`s=log10(a_T)` olarak kalır.

### Intermediate-Frequency V0.8.0 Round Trip

Exact master-point testleri korunmuştur. Ek olarak iki adjacent stitched point
arasındaki geometric midpoint sorgulanır. `LINEAR_LOG_FREQUENCY` için
`alpha=0.5`; G' ve G'' endpoint Pa değerleri üzerinde linear interpolate
edilir. Aynı reduced midpoint off-reference measured sıcaklıkta
`f_physical=f_r/10^s` ile sorgulanır; physical/reduced frequency, temperature,
`log10(a_T)`, G' ve G'' trace alanları bağımsız expected denklemle doğrulanır.

### Generalized-Maxwell Curved TRS Benchmark

Straight power-law truth korunmuş; ayrıca `G_inf=0.8 MPa`,
`G_k=[0.5,1.0,2.0] MPa`, `tau=[1e-3,1e-1,1e1] s` independent analytical
generalized-Maxwell test truth'u eklenmiştir. `273.15/293.15/313.15 K`,
`s=[+1,0,-1]` ve 0.1-decade grid ile pair/absolute shifts, joint G'/G'',
pozitif finite objective curvature, küçük residual, cloud provenance ve runtime
stitching doğrulanır. Farklı frequency bölgelerindeki log-slope değişimi
benchmark'ın gerçekten curved olduğunu gösterir.

## Limitations

- WLF/Arrhenius parameter fitting yoktur.
- Uncertainty weighting, confidence interval, bootstrap ve robust/Huber yoktur.
- Global multi-isotherm optimizer ve automatic reference selection yoktur.
- Vertical shift, smoothing, PCHIP/spline ve Prony fitting yoktur.
- Universal overlap/curvature/discrepancy/TRS acceptance threshold yoktur.
- Non-adjacent direct consistency check scope büyütmemek için ertelenmiştir.
- Importer ve automatic unit guessing yoktur.
