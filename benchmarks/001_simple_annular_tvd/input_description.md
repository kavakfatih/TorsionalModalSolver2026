# Girdi Açıklaması

## Atalet halkası

- İç yarıçap: `110 mm` (`0,110 m`)
- Dış yarıçap: `150 mm` (`0,150 m`)
- Eksenel genişlik: `50 mm` (`0,050 m`)
- Yoğunluk: `7800 kg/m³`

## Elastomer

- İç yarıçap: `90 mm` (`0,090 m`)
- Dış yarıçap: `110 mm` (`0,110 m`)
- Bağlı eksenel genişlik: `50 mm` (`0,050 m`)
- Storage shear modulus G': `1,25 MPa` (`1 250 000 Pa`)
- Sıcaklık: `293,15 K`
- Frekans çalışma noktası: `25 Hz`

Geometrik değerler `tms_units::mm_to_m`, kayma modülü ise
`tms_units::mpa_to_pa` ile SI birimlerine dönüştürülür.
